# ShopProject — интернет-магазин предметов для рабочего места

## О проекте

ShopProject — многостраничный SPA-магазин, переписанный с HTML/CSS на **React + Vite**.
Проект оформлен как настоящий продуктовый сайт: собственный бренд, каталог из 18 товаров,
корзина с формой заявки, живой поиск, чат с консультантом, тёмная тема и личный кабинет.

Bootstrap и другие UI-фреймворки не используются — вся вёрстка и анимации написаны вручную
на CSS (БЭМ, CSS-переменные, Grid/Flexbox).

## Страницы (отдельные маршруты меню)

| Маршрут | Страница | Что внутри |
| --- | --- | --- |
| `/` | Главная | обложка с фотографией, категории, преимущества, популярные товары, шаги, отзывы, FAQ, CTA |
| `/catalog` | Каталог | фильтры (категория, цена, метка, наличие), сортировка, поиск внутри каталога, сетка карточек |
| `/product/:id` | Карточка товара | галерея, блок покупки с количеством, характеристики, доставка, рейтинг и отзывы, похожие товары |
| `/about` | О бренде | история, ценности, таймлайн, команда, цитаты прессы |
| `/cart` | Корзина и заявка | несколько товаров сразу, количество, итог заказа и встроенная форма заявки |
| `/order` | Алиас | старый адрес формы заявки, открывает `/cart` |
| `/contacts` | Контакты | способы связи, квадратная Яндекс Карта с выбором из трёх адресов, памятка перед визитом и FAQ |
| `/account` | Личный кабинет | профиль, баллы, заказы, избранное, настройки (тема) |
| `*` | 404 | оформленная страница «не найдено» |

Каждая страница по содержимому занимает 2+ экрана прокрутки, главная — 4+.
Меню в шапке содержит только переходы на отдельные страницы, без якорных ссылок.

## Возможности

- **Смена темы с анимацией** — светлая/тёмная/системная, синхронный CSS-переход цветов с учётом prefers-reduced-motion, тема применяется до первой отрисовки (без вспышки).
- **Плавное появление элементов** — `IntersectionObserver` + каскадные задержки (`--reveal-delay`),
  анимированные счётчики чисел, прогресс чтения страницы, «сжатие» шапки при скролле.
- **Поиск по сайту** — модальное окно по `Ctrl/Cmd+K`, поиск по товарам, страницам и FAQ,
  навигация стрелками, подсказки с популярными запросами.
- **Чат с консультантом** — сценарии ответов по ключевым словам, быстрые ответы,
  индикатор набора, счётчик непрочитанных, кнопки-переходы внутри сообщений.
- **Личный кабинет (визуал)** — профиль, уровень лояльности, бонусы, заказы со статусами,
  избранное (общее с каталогом), адреса, переключатель темы и уведомлений.
- **Избранное** — сохраняется в `localStorage`, доступно из шапки и кабинета, с тостами.
- **Уведомления (тосты)** — единый механизм обратной связи для действий интерфейса.
- **Доступность** — семантическая разметка, `aria-*`, `focus-visible`, `prefers-reduced-motion`,
  работа модалок на нативном `<dialog>` и `Esc`.

│   ├── product/                     карточка товара и рейтинг
│   ├── search/SearchDialog.jsx      поиск по сайту
│   └── ui/                          иконки, reveal-обёртка, счётчик, заголовок секции, тосты

├── hooks/                   useReveal, useScrollState, useMediaQuery, useCountUp, useHotkey
├── data/                    товары, главная, карточка товара, о бренде, контакты/кабинет, поиск и чат

## Технологии

- React 19, React Router 7;
- Vite 8;
- CSS: переменные, БЭМ, Grid, Flexbox, `clamp()`, `backdrop-filter`, `@media (prefers-reduced-motion)`;
- `IntersectionObserver`, `requestAnimationFrame`;
- `localStorage` для темы и избранного;
- jsdom — проверка рендера страниц в тестах.

## Запуск

```bash
npm install      # установка зависимостей
npm run dev      # dev-сервер: http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # просмотр собранной версии
```

## Практика №15 на Go

Из корня репозитория запустите `go run ./practice-15/main.go`. Программа выводит в терминал цену, скидку, наличие и краткое описание товара.

Для запуска Go-версии в браузере выполните `npm run build:practice` перед `npm run dev`. Сборке WebAssembly нужен Go 1.24 или новее. В DevTools → Console результаты выводятся под меткой `Практика №15 (Go)`. GitHub Actions собирает Go-версию при публикации сайта.

## Публикация на GitHub Pages

Деплой автоматический: `.github/workflows/deploy.yml` собирает проект и публикует `dist/`
при каждом пуше в `main` (или вручную — Actions → Deploy to GitHub Pages → Run workflow).
Сайт: https://gareppro.github.io/kr1-html-css-shop/

Разовая настройка репозитория: **Settings → Pages → Source: GitHub Actions**.

Сборка в workflow запускается с `VITE_APP_BASE=/kr1-html-css-shop/` — это basename для
React Router (см. `.env.example`), потому что сайт открывается из подкаталога. После сборки
`scripts/postbuild.mjs` добавляет в `dist/`:

- `404.html` — копия `index.html`: GitHub Pages статический, и прямой переход на
  `/kr1-html-css-shop/catalog` без такого файла вернул бы 404. Pages отдаёт `404.html`
  для неизвестных путей, а маршрут отрисовывает React Router;
- `.nojekyll` — отключает обработку Jekyll на Pages.

Локальная сборка под Pages (проверка перед пушем):

```powershell
$env:VITE_APP_BASE='/kr1-html-css-shop/'
npm run build
npm run preview   # http://localhost:4173/kr1-html-css-shop/
```

Обычная `npm run build` без переменной даёт сборку с `basename: '/'` — она подходит
для локального просмотра из `dist/` и для хостинга в корне домена (не для Pages).

## Особенности реализации

- Тема и избранное хранятся в `localStorage`; системная тема отслеживается через `matchMedia`.
- Поиск и чат работают полностью на данных из `src/data` — без бэкенда.
- Личный кабинет — демонстрационный интерфейс: данные вымышленные, действия показывают тост.
- Корзина хранится в `localStorage` (`shopproject-cart`): в неё можно положить сразу
  несколько товаров, менять количество и оформлять одной заявкой. Состав заказа уходит
  в скрытом поле формы, а сообщение об успехе появляется только после отправки.
- Источники фотографий перечислены в [images/SOURCES.md](images/SOURCES.md). Снимки лежат в `public/images/` и задаются в `src/data/images.js`
  (`PRODUCT_IMAGE_FILES`, `HERO_IMAGE`, `STUDIO_IMAGE`). При ошибке загрузки
  вместо фото показывается векторный силуэт товара в палитре сайта, поэтому вёрстка
  не ломается и проект не зависит от внешних CDN.
- Карта на странице «Контакты» — виджет Яндекс Карт с поиском выбранного адреса. Список адресов хранится в `src/data/contacts.js`.
